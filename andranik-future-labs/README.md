# Telegram Desktop - mod AndranikFutureLabs

![Andranik Future Labs](mod.png)

Данная модификация Telegram Desktop (@AndranikFutureLabs) направлена на снятие ограничений, накладываемых владельцами каналов и групп на контент. Основная цель — обеспечить пользователю полный контроль над данными, включая возможность сохранения медиафайлов и пересылки сообщений из защищенных чатов.

## 🚀 Основные возможности
- **Обход запрета на копирование**: Свободное копирование текста и пересылка сообщений из любых каналов.
- **Сохранение защищенного контента**: Возможность сохранять фото, видео и документы, даже если автор установил запрет.
- **Контекстное меню**: Добавлены пункты «Сохранить как...» для всех типов медиа в защищенных чатах.

## 📂 Структура репозитория
- `bin/`: Готовый исполняемый файл `Telegram_Mod_AndranikFutureLabs.exe`.
- `src_changes/`: Исходный код только измененных файлов для прозрачности правок.
- `docs_V2_Main.md` / `.pdf`: Подробное описание внесенных изменений с указанием строк кода.
- `docs_V2_Assembly.md` / `.pdf`: Инструкция по сборке и решение возникших проблем.
